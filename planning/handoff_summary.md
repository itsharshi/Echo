# Echo — Handoff Summary for Shreya

## What Echo is

Phase 1 goal: prove open-source, zero-shot voice cloning end-to-end — capture a voice sample, clone it, and play back arbitrary text in that voice. No auth, no interview/RAG features yet (those are later phases per the original TRD). Everything must run on **open-source software and free-tier/self-hosted infra** — no paid model APIs (e.g. ElevenLabs), no paid cloud storage/compute by default.

## Decisions already made (don't re-litigate these)

- **No auth in Phase 1** — single-user app, just a bare Person record (id, name, status), no login.
- **Open-source only** — voice models must be self-hostable (XTTS-v2, F5-TTS, OpenVoice, Coqui TTS are the shortlist). No ElevenLabs or other paid TTS APIs.
- **Storage** — self-hosted MinIO (S3-compatible) for audio files, self-hosted/free-tier Postgres for metadata. No paid cloud storage.
- **CI/CD** — GitHub Actions for both CI and CD (not Jenkins) — no separate CI server to maintain. Only reconsider Jenkins if Actions genuinely can't reach the deploy target or free-tier minutes run out.
- **Hardware for model testing** — both engineers have M1 Pro MacBooks (MPS acceleration via PyTorch, no dedicated GPU). This is enough for dev/testing; production inference latency without GPU is still an open question to validate later.
- **Approach: build the app first, then evaluate models through it** — not via standalone scripts. The capture + playback UI gets built early specifically so model comparison (step 15 in the task list) happens by actually using the app.
- **Consent/legal** — deliberately deferred to ship time, not part of this build sequence.
- **GitHub account:** repo is under `itsharshi` (not `itsharshi-raga` — there are two authenticated accounts on this machine, make sure `gh auth status` shows `itsharshi` as active before pushing/creating releases).
